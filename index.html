Tentang Saya

Dari design menuju dunia programming.

Saya adalah seorang designer yang sedang belajar programming dari nol. Karena saya sudah terbiasa dengan visual, layout, warna, dan komposisi, saya ingin mengembangkan skill tersebut menjadi kemampuan membuat website.

Saat ini fokus saya adalah memahami dasar-dasar web development, mulai dari struktur HTML, styling menggunakan CSS, sampai interaksi sederhana menggunakan JavaScript.

Skill Yang Dipelajari

Fondasi awal sebagai Front-End Developer.

HTML

Membuat struktur halaman website seperti heading, paragraf, gambar, tombol, dan section.

CSS

Mengatur warna, layout, ukuran teks, jarak, background, responsive, dan tampilan modern.

JavaScript

Membuat website menjadi interaktif seperti klik tombol, slider, popup, dan animasi dasar.
